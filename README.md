# 🎓 Student Registration System

A simple and responsive web-based Student Registration System built using HTML, CSS and JavaScript.

## 🚀 Features

- Student registration form
- Enter student name, email and mobile number
- Select course and semester
- Enter city and address
- Form validation
- Display registered students
- Delete student records
- Student count
- Data stored using Local Storage
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 📂 Project Structure

Student-Registration-System/
│
├── index.html
├── style.css
└── script.js

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Use Live Server or open the HTML file in a browser.
5. Start registering students.

## 🎯 Purpose

This project was created to practice web development, form handling, JavaScript, DOM manipulation and browser Local Storage.
